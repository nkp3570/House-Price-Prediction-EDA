# House Price Prediction — Exploratory Data Analysis

## Project
This repository contains an exploratory data analysis (EDA) of the Kaggle House Prices: Advanced Regression Techniques training dataset.

## Files
- `House_Price_EDA.ipynb` — executed Jupyter notebook with data checks, summary statistics, and eight charts.
- `House_Price_EDA_Report.pdf` — PDF report/printout of the EDA findings and charts.
- `train.csv` — original training dataset from Kaggle.

## How to run
1. Download all three files into the same folder.
2. Install Python and Jupyter Notebook, or upload the notebook and CSV to Google Colab.
3. Open `House_Price_EDA.ipynb`.
4. If using Google Colab, upload `train.csv` when prompted or upload both files to the same session.
5. Run the notebook cells from top to bottom.

## Scope
This notebook performs EDA only. It does not train machine-learning models. It examines the dataset structure, missing values, duplicates, summary statistics, and relationships between selected house features and sale price.

## Data source
Kaggle. (n.d.). *House prices: Advanced regression techniques*.  
https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data
